# 参考图级人像美化重构

## Goal

将当前单一皮肤 mask 与 Gaussian 残差处理重构为纯 MATLAB 的全裸露皮肤分割、动态五官保护及亮度/色度多尺度修复。最大档接近参考图的强工作室修图效果：大幅淡化雀斑、色斑和皱纹，同时保留眉毛、睫毛、眼睛、鼻翼、嘴唇、脸型与面部明暗结构。

## Background

- 用户提供的 `80/80r` 与 `81/81r` 定义目标质感；参考图用于视觉方向，不做逐像素拟合。
- 当前真人回归显示：弱化曲线时雀斑残留，增强曲线时皮肤、眉毛、鼻部及面部低频结构会被磨没。
- 现有算法只处理人脸框内 Y 通道，无法覆盖颈、手和手臂，也无法消除色度型雀斑。
- MATLAB R2024a 已安装 Image Processing Toolbox、Computer Vision Toolbox 与 Deep Learning Toolbox，但课设要求纯 MATLAB，且本任务不下载或引入外部预训练模型。
- 本机 EyePair、Nose、Mouth 级联模型可用，但在偏转人脸上会缺失或误检，不能作为唯一保护依据。

## Requirements

1. 根据脸部可靠肤色样本建立自适应 YCbCr 模型，并扩展到全图裸露皮肤，包括脸、颈、手和手臂。
2. 保留与脸或颈相连的皮肤区域，并允许保留颜色高度匹配、面积足够的独立手部/手臂连通域；排除背景、头发、衣物和小噪点。
3. 在加载图像时一次生成并缓存全图皮肤 mask、人脸皮肤 mask、五官保护 mask、原图尺寸与人脸框。
4. 对旋转人脸区域尝试 EyePair、Nose、Mouth 检测，只采纳满足解剖顺序和相对位置约束的结果；失败时使用原尺度梯度、色度及相对人脸位置回退，不阻断美颜。
5. 眼睛、眉毛、睫毛和嘴唇强保护；鼻部仅保护鼻梁、鼻翼和鼻孔结构，不整块排除。
6. 磨皮同时处理 Y、Cb、Cr：低频脸部结构始终保留，中尺度斑点显著衰减，最大档仍保留约 20% 高频自然纹理。
7. 美白只作用于检测到的裸露皮肤，使用有上限且全程单调的中间调曲线，保留亮度排序和局部对比，不改变背景、头发或衣物。
8. 所有 soft mask 由图像内容生成；不得以固定椭圆或固定人体形状作为最终效果区域。
9. 保持 GUI 布局、滑块范围、保存格式、输出尺寸与画幅比例不变；零强度输出与输入逐元素相同。
10. 允许打开图像时增加约 1–3 秒预分析；缓存后的滑块预览目标不超过约 250 ms。

## Public Interfaces

- `beautyContext = prepareBeautyContext(inputImage, faceBox)`
- `outputImage = beautifyImage(inputImage, params, faceBox, beautyContext)`；第四参数可选，三参数调用保持兼容。
- `params = recommendBeautyParams(inputImage, faceBox, beautyContext)`；第三参数可选。
- `beautyContext` 必含 `skinMask`、`faceSkinMask`、`featureProtectionMask`、`imageSize` 和 `faceBox`。

## Acceptance Criteria

- [ ] `0/25/50/75/100` 下纹理能量、离散雀斑对比度与皮肤亮度连续变化。
- [ ] 最大磨皮时离散雀斑对比度至少降低 70%，非五官皮肤区域仍保留不少于原始值 10% 的微纹理。
- [ ] 仅磨皮 100、仅美白 100、二者同时 100 时，鼻梁/脸颊及眼窝/脸颊低频对比度符号不反转且至少保留 80%。
- [ ] 眼眉、眼睛、鼻翼和嘴唇主要梯度至少保留 85%。
- [ ] 断开的手部或手臂皮肤得到处理；近似肤色背景、头发、衣物及普通背景保持在既有保护阈值内。
- [ ] Cb/Cr 色斑随磨皮连续减弱，但受保护五官区域的色度和锐度保持。
- [ ] context 缺失时可自动构建；不匹配时返回明确 `InvalidContext`；零强度不触发预处理且完全返回原图。
- [ ] GUI 只在载入新图时准备 context；拖动、松开、一键美颜和重置均正确复用或保留缓存，失败加载会清空缓存。
- [ ] 现有算法、人脸检测、GUI 保存与尺寸契约测试全部通过，相关 MATLAB 文件 `checkcode` 为零且 `git diff --check` 通过。
- [ ] 用户用 `80.jpg`、`81.jpg` 做 GUI 视觉验收：最大档接近对应参考图的净肤程度，同时五官和脸部立体结构清晰。

## Out of Scope

- 不使用 Python、MediaPipe、LLM、外部预训练模型或新增运行时依赖。
- 不改变脸型、五官比例、背景曝光、GUI 布局、滑块范围或保存格式。
- 不将用户参考图片复制或提交进仓库。

## Verification Ownership

- 实现方完成自动化测试、静态检查、性能测量和参考图非提交对照。
- 用户完成最终真人图 GUI 视觉验收。
