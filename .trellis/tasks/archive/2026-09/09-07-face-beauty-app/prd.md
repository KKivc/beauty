# 人脸图像导入与单人脸检测 GUI（MVP）

## Goal

在 MATLAB App Designer 中交付一个可演示的图像导入与单人脸检测界面：用户导入一张 JPG 或 PNG 照片，查看原图及检测结果的并排展示。

## Confirmed Facts

- 当前仓库没有既有 MATLAB 算法、GUI 入口或测试代码。
- 项目可依赖 MATLAB Image Processing Toolbox 和 Computer Vision Toolbox。
- 人脸检测使用 `vision.CascadeObjectDetector`。
- 使用 MATLAB R2024a。

## In Scope

- 使用 MATLAB App Designer 实现 GUI，并在同一界面左右并排显示原图与检测结果。
- 支持导入 JPG、PNG 图像；本 MVP 以彩色图像为输入范围。
- 仅接受检测到恰好一张人脸的图像。未检测到人脸或检测到多张人脸时，提示用户重新选择图像，且不提供手动框选。
- 右侧检测结果显示带人脸框的完整原图。
- 支持保存右侧检测结果；保存格式限于 JPG、PNG，默认沿用输入图像格式。

## Out of Scope

- 磨皮、美白、一键美颜、参数调节及实时预览。
- 信息熵、标准差、平均梯度和处理耗时展示。
- 约 2 秒的实时预览性能目标及预览/原尺寸重算策略。
- BMP、TIF、灰度图、透明通道、EXIF 方向和 DPI/PPI 元数据兼容性。
- 多人脸处理、手动框选、瘦脸、大眼或其他五官重塑功能。

## Requirements

- 打开图像后，原图显示在左侧，并立即自动执行人脸检测；右侧显示单人脸检测结果。
- 自动检测后，只有检测到恰好一张人脸时才显示成功结果。
- 对零张或多张人脸的输入，提示用户重新选择图像，且不产生成功检测结果。
- 保存操作仅在已有成功检测结果时可用，保存右侧带人脸框的完整图像；否则提示用户先导入并成功检测。

## Acceptance Criteria

- [ ] 在 MATLAB R2024a 的 App Designer 中可选择一张 JPG 或 PNG 彩色图像，并同屏显示原图和检测结果区域。
- [ ] 对恰好一张人脸的输入，可在右侧显示成功检测结果。
- [ ] 对零张或多张人脸的输入，应用提示用户重新选择图像，且右侧不显示成功检测结果。
- [ ] 对成功检测结果，可选择路径保存为 JPG 或 PNG；重新读取文件后可验证输出像素宽高与输入图像一致。
- [ ] MVP 不出现美颜、参数滑块、指标面板或多人脸处理入口。

## Deferred Follow-up Tasks

1. 固定预设美颜和重置。
2. 参数化交互：独立的磨皮/美白滑块、数值显示、预设值同步和实时预览。
3. 指标与性能：三项客观指标、计时、预览缩放和性能验收。
4. 输入输出兼容性：BMP/TIF、灰度图和图像元数据保留策略。
