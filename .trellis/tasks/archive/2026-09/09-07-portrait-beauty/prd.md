# 人像美颜功能

## Goal

在现有 MATLAB GUI 基础上实现人像美颜能力。用户可以打开人像图片，同屏查看原图与处理结果，通过磨皮、美白参数调节实时预览，并支持一键美颜、重置原图和保存处理结果。

## Current Repository Facts

- 当前 GUI 入口为 `gui/faceDetectionApp.m`，基于 App Designer 风格 `matlab.apps.AppBase` 手写 UI。
- 已确认直接改造当前 `faceDetectionApp.m` 为人像美颜 GUI，复用打开图像、主脸检测、左右并排显示和保存尺寸校验能力。
- 当前界面已支持打开 JPG/PNG、左右并排显示原图和检测结果、保存结果。
- 当前算法层只有主脸检测与检测框绘制：`src/detectSingleFace.m`、`src/annotateFaceDetection.m`。
- 当前 GUI 只接受三通道 RGB JPG/PNG，并选择最大且相对居中的前景人脸作为处理目标。
- 已确认 MVP 仅支持 `uint8` 三通道 RGB 输入，不支持 `uint16` PNG 或其他数值类型。
- 当前测试只覆盖检测辅助函数的输入校验和尺寸保持。
- 已改为主脸模式：允许画面中存在背景人物，使用多角度人脸检测选择最大且相对居中的前景人脸；美颜处理优先面向该人脸/肤色区域，避免背景被过度处理。

## Requirements

- GUI 必须同屏并排显示原图和美颜结果。
- GUI 必须支持打开图像、保存结果、磨皮参数调节、美白参数调节、一键美颜、重置原图。
- 磨皮参数变化应触发实时预览：拖动滑块过程中持续更新，并允许约 `200 ms` 节流；松开滑块后必须完成一次最终刷新。
- 美白参数变化应触发实时预览：拖动滑块过程中持续更新，并允许约 `200 ms` 节流；松开滑块后必须完成一次最终刷新。
- 磨皮强度使用 `0–100` 滑块，默认值为 `35`。
- 美白强度使用 `0–100` 滑块，默认值为 `25`。
- 一键美颜应根据当前图像的人脸肤色亮度、局部纹理和光照情况，自动推荐磨皮与美白强度；每张图像允许得到不同参数，不得使用固定的 `45/30`。
- 重置原图应清除当前美颜效果，将磨皮和美白强度设为 `0`，右侧显示未处理原图。
- 一键美颜只自动推荐参数，用户仍可通过两个滑块继续调整；推荐值允许覆盖完整 `0–100` 范围，不使用固定参数或人为 `55` 上限。
- 最终保存结果必须保持输入图像的像素宽高（像素分辨率）、三通道结构和画幅比例，不得裁剪、拉伸或变形；处理过程中的临时缩放或多尺度计算除外。
- 磨皮效果应淡化皮肤斑点、细纹等瑕疵，同时保留五官轮廓和关键细节。
- 美白效果应自然均匀，整体色调和谐，避免明显偏色和假白。
- 输出不得出现明显光晕、伪轮廓、边缘模糊失真。
- 输出不得改变人脸整体结构和比例，不得产生变形扭曲。
- 处理耗时应按单幅图像记录并在界面展示。
- 输出评价指标应包含信息熵、标准差、平均梯度和处理耗时。
- GUI 必须设置独立的指标展示区域，显示当前结果的“信息熵”“标准差”“平均梯度”和“单幅图像处理耗时”；每次美颜预览完成后同步更新。
- 指标统一基于输出图像的 `rgb2gray` 灰度图计算：信息熵使用 256 级灰度直方图和以 2 为底的熵；标准差使用总体标准差（分母为像素总数 `N`）；平均梯度使用 MATLAB `gradient` 的水平、垂直梯度幅值全图平均值，边界采用默认单边差分。
- 处理耗时仅统计一次 `beautifyImage` 调用，不包含人脸检测、指标计算、绘图和保存。

## Constraints

- 使用 MATLAB R2024a 或更高版本实现。
- 依赖 Computer Vision Toolbox 和 Image Processing Toolbox；缺少必需工具箱时必须给出明确错误。
- 算法、GUI 回调和评价指标应尽量分离，便于单独验证。
- 仅支持 `uint8` 三通道 RGB JPG/PNG 输入；其他位深或数值类型必须明确提示不支持，不得静默转换。
- 输入图像必须至少检测到一个可识别的人脸；检测到多张人脸时选择最大且相对居中的前景人脸，未检测到可识别人脸时提示用户更换图片。
- 注释使用中文，English 等技术名词按需保留。
- 临时缩放或多尺度计算结束后，输出必须恢复原始尺寸。
- `beautifyImage` 的磨皮和美白参数必须是有限数值标量且位于 `0–100`；缺失字段、非数值、`NaN`、`Inf` 或越界值必须报错，不得自动 clamp。
- 一键推荐值根据当前图像计算，可高于 `55`；算法通过 mask、亮度裁剪和边缘保护控制实际输出，避免过曝、光晕和边缘失真。
- MVP 不承诺保留 DPI/像素密度、ICC 色彩配置或 EXIF 等文件元数据；这些元数据不属于当前保存验收范围。

## Acceptance Criteria

- [ ] 打开有效且包含可识别主脸的 `uint8` RGB JPG/PNG 后，左侧显示原图，右侧显示美颜预览；背景人物不应成为处理目标。
- [ ] 打开 `uint16` PNG 或其他非 `uint8` 图像时，明确提示不支持且不生成美颜结果。
- [ ] 拖动磨皮滑块过程中右侧结果持续更新，松开后完成最终刷新。
- [ ] 拖动美白滑块过程中右侧结果持续更新，松开后完成最终刷新。
- [ ] 磨皮滑块范围为 `0–100`，默认值为 `35`。
- [ ] 美白滑块范围为 `0–100`，默认值为 `25`。
- [ ] 点击一键美颜后，根据当前图像计算并显示一组完整 `0–100` 范围内的自适应磨皮和美白参数，并生成处理结果；不同图像可得到不同参数，推荐值允许高于 `55`。
- [ ] 点击重置原图后，磨皮和美白参数设为 `0`，右侧预览恢复为未美颜原图。
- [ ] 保存结果后，重新读取文件确认像素宽高（像素分辨率）和通道数与输入一致。
- [ ] 保存结果保持输入画幅比例，不裁剪，不拉伸。
- [ ] 使用固定的 4 张测试图进行人工验收，覆盖不同尺寸、肤色、姿态和光照条件。
- [ ] 在 4 张测试图上，结果均能淡化皮肤瑕疵并保持五官轮廓和关键细节清晰。
- [ ] 在 4 张测试图上，结果均无明显偏色、假白、光晕、伪轮廓或边缘模糊失真。
- [ ] 在 4 张测试图上，人脸结构和比例均未改变；背景和头发不过度处理。
- [ ] GUI 指标区域显示当前结果的“信息熵”“标准差”“平均梯度”和“单幅图像处理耗时”，并在滑块、一键美颜和重置后的预览完成时更新；重置后前三项为原图指标，处理耗时为 `0 ms`。
- [ ] 算法函数可独立调用并保持输出尺寸与输入一致。
- [ ] 算法函数对缺失、非数值、非标量、`NaN`、`Inf` 和越界参数返回稳定错误。
